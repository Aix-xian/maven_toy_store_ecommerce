# Excel 看板使用说明

## 打开与选择期间

打开 [最终经营看板](../output/ecommerce_dashboard.xlsx)。工作簿包含四个展示视图、四份汇总输入和六张原生图表，已整理坐标轴与显示布局。当前保存期间为 2014 年全年，不依赖数据库连接或 Power BI。

在“经营总览”的 B4 选择起始月份、E4 选择结束月份。其他视图引用同一期间。可选范围为 2012-04 至 2015-02 共 35 个可比月份；首尾观测月保留在底层数据，不进入默认比较。

打开后允许 Excel 自动重算。必要时将计算选项设为“自动”，按 Ctrl+Alt+F9 完整计算。起止倒置、空白或边界月份应提示“请检查月份”，不可用指标不能作为零解释。

## 视图与口径

| 视图 | 主要内容 | 时间与分母 |
| --- | --- | --- |
| 经营总览 | 会话、订单、收入、转化、客单价、订单结构 | 订单指标按下单月，会话指标按会话月；长期趋势始终显示全部可比月。 |
| 渠道设备 | 来源与设备的规模、转化、单位访问收入 | 按会话月；candidate 为候选来源分类，零分母显示 n.a.。 |
| 购买漏斗 | 设备阶段人数与推进率 | 同一会话内有序推进，各阶段分母为前一个有效阶段。 |
| 商品退款 | 商品贡献、主次商品和统一窗口退款 | 按原订单月；30 天退款率同时排除观察不足的分子和分母。 |

四张数据页分别保留月、月/渠道/设备、月/营销维度/落地页、月/商品粒度。源日期和来源说明保留在输入页；原始浏览明细不装入 Excel。

## 数值与显示检查

2014 全年销售额应为 1,075,612.19 美元，订单 16,860，客单价约 63.80 美元。2014-12 单月销售额为 144,823.02 美元，订单 2,314，客单价约 62.59 美元。

当前验证记录见 [Excel 检查](../output/excel_validation_report.json)，记录工作簿指纹、表和图数量及保存期间关键指标缓存的匹配情况。缓存核对不代表所有月份的动态切换均已验证。切换月份后还需检查其他视图标签、指标与图表是否同步，并保存计算缓存。

## 数据刷新

下载原始数据并按环境说明重算各模块及 review 程序后，在项目隔离环境执行：

```bash
env/python/bin/python -B src/build_excel_dashboard.py
```

构建程序覆盖同名最终工作簿。数据更新后的工作簿需要在 Excel 重算并检查图表、轴、列宽与图例，保存后再执行仓库检查工具。看板不支持手工追加原始明细后自动扩展。

## 解释边界

金额单位为美元，销售额未扣退款，商品页另列已观测退款与销售减退款。缺少退款后的成本冲回和其他经营费用，不计算净利润。退款截止为最后一次已观测事件的代理，不证明源数据逐日完整。
