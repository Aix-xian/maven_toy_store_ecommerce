## 关键处理决定

2026-11-04：补齐 GitHub 仓库所需的代码、文档、汇总结果、依赖清单和最终看板，保留已有 README、Git 忽略规则及文件属性设置。将占用 assets 目录名称的空文件替换为数据来源与字典目录。仓库检查程序排除 Git 元数据、本地运行环境及生成数据；提交前重新执行离线测试和最终看板缓存核对，不重新查询数据库。此次整理无额外数据问题。

主比较区间为 2012-04 至 2015-02，保留 37 个月但只将中间 35 月纳入主比较。订单指标按下单月，会话指标按会话月。退款使用最后一次已观测事件作为截止代理，并提供统一 30 天窗口；该代理不证明采集完整。

各模块先保留粒度，再关联和汇总。比率使用分子分母合计，金额计算使用 Decimal。渠道候选、描述性分解、漏斗差异与退款率均不作为因果证明，销售减退款不称为净利润。
