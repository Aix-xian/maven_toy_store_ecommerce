# 月度经营指标口径

## 分析目标与数据范围

解释玩具电商的访问、下单和销售表现如何变化，为后续渠道、漏斗和商品分析建立基准。所有金额单位为美元。事件时间按数据集原始 DATETIME 使用，原数据未说明时区，不做时区转换；过程记录时间使用 Asia/Shanghai。

已核实的访问和订单范围均始于 2012-03-19、止于 2015-03-19。保留 2012-03 和 2015-03，并标为 boundary_month。可比区间采用 2012-04 至 2015-02，标为 comparable_month。该标签表示排除首尾观测月的分析约定，不表示已独立证明数据源在每个自然日都采集完整。

脚本根据访问表和订单表的实际边界推导月份，补齐中间日历月，不把没有事件的月份直接删去。实际生成 37 个月份，其中 35 个可比月份。

## 两种时间归属

- 订单口径：按 orders.created_at 所在月份归属，用于订单数、销售额、商品成本和客单价。
- 会话口径：按 website_sessions.created_at 所在月份归属。先把订单汇总成每次会话一行，再关联会话，计算转化会话数和会话收入。
- 会话发生在月底、订单发生在次月时，会话口径收入归到会话月份，订单口径收入归到下单月份。因此每次访问收入使用 session_sales_usd，而不是直接使用当月下单口径 sales_usd。
- 同一会话即使产生多笔订单，转化会话仍只计一次。脚本保留 session_orders 和 converted_sessions，分别表示两种数量。
- 会话收入和转化基于当前可观测订单；末端会话的观察时长较短，边界月份保留但不参与主环比。

## 指标字典

| 字段 | 含义与计算 | 时间归属 |
| --- | --- | --- |
| month_start | 月份第一天，作为月度键 | 自然月 |
| period_status | comparable_month 或 boundary_month | 分析约定 |
| sessions | 网站会话数 | 会话开始时间 |
| converted_sessions | 产生至少一笔可观测订单的会话数 | 会话开始时间 |
| session_orders | 这些会话产生的订单数，可大于转化会话数 | 会话开始时间 |
| session_sales_usd | 这些会话产生的订单金额合计 | 会话开始时间 |
| orders | 订单数 | 下单时间 |
| sales_usd | 订单 price_usd 合计，未扣退款 | 下单时间 |
| cogs_usd | 订单 cogs_usd 合计 | 下单时间 |
| conversion_rate | converted_sessions / sessions | 会话开始时间 |
| aov_usd | sales_usd / orders，客单价 | 下单时间 |
| revenue_per_session_usd | session_sales_usd / sessions，每次访问收入 | 会话开始时间 |
| product_margin_before_refunds_usd | sales_usd - cogs_usd，退款前销售额与商品成本差额 | 下单时间 |
| sessions_mom | 会话数 / 上月会话数 - 1 | 相邻可比月份 |

| sales_mom | 销售额 / 上月销售额 - 1 | 相邻可比月份 |
| conversion_rate_change_pp | (本月转化率 - 上月转化率) × 100，单位为百分点 | 相邻可比月份 |

| revenue_per_session_mom | 每次访问收入 / 上月每次访问收入 - 1 | 相邻可比月份 |

## 金额、比率与环比处理

- 销售额尚未扣除退款。成本差额不包含广告、人员、仓储等其他费用，不作为净利润。
- 退款记录延续至 2015-04-01；基础销售指标不按退款发生月直接扣减，商品模块另行定义订单归属退款、退款事件与统一观察窗口。
- 金额和比率使用 Decimal 计算；导出时保留最多八位小数，计算与核对发生在导出舍入前。
- 比率导出为小数，例如 0.025 表示 2.5%。环比同样为小数；百分点字段已乘 100，例如 0.2 表示提高 0.2 个百分点。
- 分母为零时保留空值，JSON 中为 null，CSV 中为空白。环比只计算相邻的两个可比月份；首个可比月份不与之前的边界月份比较。
- 汇总期的转化率、客单价和每次访问收入使用汇总分子 / 汇总分母，不对各月比率做算术平均。

## 结果核对

脚本核对数据库当前的访问/订单数量和时间边界与质量报告是否一致；核对月份连续且唯一；核对按月汇总后的访问数、转化会话数、订单数、销售额、商品成本与原表总量一致；核对会话口径收入合计与订单原表收入合计一致，并检查每个月的转化边界和非负数量/金额。

检查通过后输出：

- output/monthly_overview.csv：全部月份，保留边界标签。
- output/monthly_overview_comparable.csv：仅可比月份，用于主趋势展示。
- output/monthly_overview_report.json：运行状态、口径来源、核对记录、汇总指标及月度明细。

质量报告中的行数和时间边界能够检查数据范围是否变化，不能替代逐字段内容校验；修改业务数据后应先重新运行质量检查。

## 商品、客单价与退款扩展

按下单月统计商品与订单篮子，退款同时保留累计已观测口径和统一窗口资格口径，不把销售减退款当净利润。完整定义和观察截止局限见 [商品与退款方法](product_methodology.md)。
